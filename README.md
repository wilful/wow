# Гильдия Durotar — сайт гильдии World of Warcraft: Forever

Приветственная (первая) страница гильдейского сайта под **World of Warcraft: Forever** (версия
на основе Classic: уровни 1–60, без мификов): тёмный камень, золото и пергамент в духе игры.
Сейчас есть главная, заявка и макросы; дальше — состав, расписание и правила.

## Стек

- [Astro](https://astro.build) (статическая генерация)
- страницы `src/pages/index.astro`, `join.astro` и `macros.astro` со встроенными стилями
- все изображения — из игры World of Warcraft (скриншоты с [warcraft.wiki.gg](https://warcraft.wiki.gg/), лежат в `public/img/`); шрифты (Cinzel Decorative, Forum, PT Serif) скачаны с Google Fonts и лежат локально в `public/fonts/` — сторонних запросов со страницы нет
- публикация на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)

## Заявка в гильдию (`/join/`)

Страница `src/pages/join.astro` собирает код заявки `DUR1-...` и готовую строку
`/w <офицер> ...` для чата WoW. Данные гильдии — реалм, фракция и
офицеры — лежат в `src/data/guild.ts`.

Допустимые роли зависят от класса: форма скрывает недоступные роли и выбирает
допустимую при смене класса. Аддон повторно проверяет комбинацию из кода.

Код разбирает аддон Durotar из соседнего репозитория `AddOns/Durotar`: он
слушает шёпот, показывает карточку и умеет пригласить игрока. Ссылка
`?ref=VIL` запоминает, кто пригласил. У офицера в `guild.ts` есть `name` —
оно же подставляется в `/w` — и `code` (например, `VIL`).

## Макросы (`/macros/`)

Страница `src/pages/macros.astro` — шпаргалка с общими и классовыми макросами:
описание, готовый код и кнопка «Скопировать». Данные лежат в `src/data/macros.ts`:
`generalMacros` и `classMacros` (по два на класс, девять классов из `applicationClasses`).
Классы и их цвета совпадают с заявкой.

Вкладки «Общие / Классовые», выбор класса и поиск пишут состояние в ссылку
(`?tab=class&class=WAR&q=фокус`), так что нужный вид макросов можно отправить
в чат. Названия способностей в коде — под русский клиент игры; при английском
клиенте заменяются слова в `code`, логика макроса не меняется.

Картинка в шапке — игровой скриншот гоблина-механика с warcraft.wiki.gg,
лежит в `public/img/goblin-tinker.jpg`.

## Локальный запуск

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в dist/
npm run preview # просмотр собранной версии
npm run check   # проверка типов Astro
```

Новые разделы добавляются как страницы в `src/pages/`.
