# Гильдия Durotar — сайт гильдии World of Warcraft: Forever

Приветственная (первая) страница гильдейского сайта под **World of Warcraft: Forever** (версия
на основе Classic: уровни 1–60, без мификов): тёмный камень, золото и пергамент в духе игры.
Сейчас есть главная, большие карты мира, заявка, макросы и аддоны; дальше — состав, расписание и правила.

## Стек

- [Astro](https://astro.build) (статическая генерация) и [Leaflet](https://leafletjs.com/) для карты
- страницы `src/pages/index.astro`, `map.astro`, `join.astro`, `macros.astro` и `addons/` со встроенными стилями
- все изображения — из игры World of Warcraft (скриншоты с [warcraft.wiki.gg](https://warcraft.wiki.gg/), лежат в `public/img/`); шрифты (Cinzel Decorative, Forum, PT Serif) скачаны с Google Fonts и лежат локально в `public/fonts/` — сторонних запросов со страницы нет
- публикация на GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`)

## Заявка в гильдию (`/join/`)

Страница `src/pages/join.astro` собирает код заявки `DUR1-...` и готовую строку
`/w <офицер> ...` для чата WoW. Данные гильдии — реалм, фракция и
офицеры — лежат в `src/data/guild.ts`.

Допустимые роли зависят от класса: форма скрывает недоступные роли и выбирает
допустимую при смене класса. Аддон повторно проверяет комбинацию из кода.

Код разбирает аддон Durotar из соседнего репозитория `AddOns/Durotar`: он
слушает шёпот, показывает карточку и умеет пригласить игрока. Ссылка
`?ref=VIL` запоминает, кто пригласил. У офицера в `guild.ts` есть `name` —
оно же подставляется в `/w` — и `code` (например, `VIL`).

Плашки «Танки / Хилы / ДД» в разделе «Нам нужны герои» на главной ведут на
`/join/?role=TANK` (или `HEAL`, `DD`): форма сама выбирает первый класс,
который умеет эту роль. Параметр `?class=WAR` выбирает класс, а `?role=TANK&ref=VIL`
работает вместе с приглашением.

## Макросы (`/macros/`)

Страница `src/pages/macros.astro` — шпаргалка с общими и классовыми макросами:
описание, готовый код и кнопка «Скопировать». Данные лежат в `src/data/macros.ts`:
`generalMacros` и `classMacros` (по три на класс, девять классов из `applicationClasses`).
Классы и их цвета совпадают с заявкой, а самые ходовые карточки помечены значком
«Хит» (поле `popular`).

Вкладки «Общие / Классовые», выбор класса и поиск пишут состояние в ссылку
(`?tab=class&class=WAR&q=фокус`), так что нужный вид макросов можно отправить
в чат. Названия способностей в коде — под русский клиент игры; при английском
клиенте заменяются слова в `code`, логика макроса не меняется.

Кнопка **«Создать в игре»** копирует строку вида
`/run CreateMacro("Рывок", "INV_Misc_QuestionMark", "...")`: её вставляют в чат
вне боя, и игра создаёт макрос сама (API `CreateMacro` есть в клиенте Forever).
Имена для этой строки — в `macroNames`, лимит 16 символов; обычное
«Скопировать» остаётся как запасной ручной путь.

Картинка в шапке — игровой скриншот гоблина-механика с warcraft.wiki.gg,
лежит в `public/img/goblin-tinker.jpg`.

## Аддоны (`/addons/`)

Раздел об аддонах гильдии: каталог `src/pages/addons/index.astro` и страница
аддона `src/pages/addons/[slug].astro` (один шаблон на все аддоны). Данные
лежат в `src/data/addons.ts`: название, слоган, вкладки и установка. Чтобы
добавить аддон, допиши объект в массив `addons` — страница `/addons/<slug>/`
появится сама.

Первый аддон — **Дуротар** (`Durotar`) из соседнего репозитория `AddOns/`:
заявки с сайта в игре, согильдейцы рядом и учёт золота. Обложка — игровой кадр
пустыни Дуротар, лежит в `public/img/hero-durotar.jpg`.

## Карта мира (`/map/`)

Страница `src/pages/map.astro` — полноэкранная интерактивная карта Азерота
эпохи Forever на Leaflet: зоны, города, подземелья, рейды, PvP, боссы,
транспорт и география (озёра, перевалы, достопримечательности). Можно
перетаскивать карту, приближать колесом и щипком, переключать регион,
включать слои и искать объект по названию.

Карты — игровые карты World of Warcraft: Forever в двойном разрешении
(`2004 × 1336`) из `public/img/map/`: `azeroth.jpg`, `eastern-kingdoms.jpg`,
`kalimdor.jpg`. Объекты и их координаты — `src/data/worldmap.ts`; координаты
заданы в процентах от карты. Внешних запросов нет: Leaflet и шрифты лежат
локально, изображения — из игры (warcraft.wiki.gg).

## Локальный запуск

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в dist/
npm run preview # просмотр собранной версии
npm run check   # проверка типов Astro
```

Новые разделы добавляются как страницы в `src/pages/`.
