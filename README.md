# WoW Forever — лендинг

Превью-лендинг русскоязычного игрового проекта в духе классического World of Warcraft.
Стиль — high fantasy: старое золото, арканный фиолет, руны, туман, силуэты драконов и
иллюстрации, нарисованные прямо в SVG.

## Стек

- [Astro](https://astro.build) (статическая генерация, без сервера)
- чистый CSS и один клиентский скрипт — никаких тяжёлых библиотек
- публикация на GitHub Pages через GitHub Actions

## Локальный запуск

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # сборка в dist/
npm run preview # просмотр собранной версии
```

## Публикация

1. Залейте репозиторий на GitHub.
2. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
3. Пуш в `main` (или `master`) — workflow `.github/workflows/deploy.yml` сам соберёт сайт и
   опубликует его.

`base` для GitHub Pages workflow вычисляет автоматически: для репозитория вида
`<user>.github.io` это `/`, для проектного репозитория — `/<имя-репозитория>`.
Локально можно задать вручную: `BASE_PATH=/my-repo npm run build`.

## Что где лежит

| Файл | Назначение |
| --- | --- |
| `src/pages/index.astro` | сборка страницы из блоков |
| `src/components/*.astro` | секции: герой, о проекте, старт, реалмы, лор, событие, новости, FAQ, подвал |
| `src/components/Lore.astro` | лор Азерота: факты, лента эпох и SVG-иллюстрации (дракон, карта, кристаллы) |
| `src/styles/global.css` | вся тема: цвета, руны, панели, кнопки, адаптив |
| `src/scripts/main.js` | меню, анимации, таймер, загрузка новостей |
| `public/news.json` | новости лендинга — обновляются без пересборки |

## Живые элементы (работают без бэкенда)

- таймер до ближайшей субботы, 20:00 МСК;
- новости подгружаются из `public/news.json`;
- угольки на canvas, появление блоков при скролле, мобильное меню.

## Перед публикацией замените заполнители

- ссылки на Discord, форум и файлы клиента (сейчас это кнопки-заглушки и текст в подвале);
- цифры онлайна реалмов — сейчас демонстрационные, помечены в тексте;
- названия реалмов, рейты, даты и новости — под реальный проект.

Иллюстрации (дракон, ночной Азерот, карта, кристаллы) нарисованы в SVG прямо в компонентах,
поэтому весят считаные килобайты и остаются резкими на любом экране. При желании их можно
заменить на арт проекта, сохранив те же размеры контейнеров.
