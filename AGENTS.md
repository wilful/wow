# Инструкции агента

## Медиа и ресурсы (обязательно)

- **Все фотографии, иллюстрации и прочие картинки на сайте берутся только из игры
  World of Warcraft** — игровые скриншоты или официальные арт-материалы Warcraft/WoW.
- Источник по умолчанию: **warcraft.wiki.gg** (общедоступный вики-ресурс по WoW).
  Скриншоты скачиваются в `public/img/` (главная)
  и подключаются локально, а не по горячим ссылкам.
- Реальные (неигровые) фотографии — пейзажи, замки, города из реального мира —
  **не использовать**, даже как «настроение». Сайт посвящён миру Azeroth.
- В подвале страниц указывать источник изображений (warcraft.wiki.gg).
- Новые картинки: кладём файлы в `public/img/`, подключаем через
  `${base}img/<имя>.jpg` (учитывать `BASE_PATH`), alt — по-русски, описывающий кадр.

## Проверка

- Перед сдачей: `voiceide-env node -- env XDG_CONFIG_HOME=/tmp/astro-config npm run build`
  и `npm run check` (0 ошибок).
